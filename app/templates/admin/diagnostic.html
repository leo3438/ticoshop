Tester le format sur une vraie Switch

Ce dépôt de test contient un seul paquet minimal (un fichier texte). Il permet de vérifier en une minute que votre version de tico accepte le format généré par ticoshop :

{{ diag_url }}
  1. tico › Store › Sources › Ajouter un dépôt › l'adresse ci-dessus.
  2. Le dépôt « ticoshop · test » doit afficher 1 paquet. Une erreur « Failed to parse » ou « Needs a newer tico » indique un problème de format.
  3. Installez « ticoshop test » : le fichier sdmc:/switch/ticoshop-test/README.txt doit apparaître.
  4. Désinstallez-le, puis retirez la source de test.

Si le test passe mais qu'un de vos paquets échoue, comparez-le avec l'index de test et ajustez le paquet (ou ses « champs supplémentaires »).
