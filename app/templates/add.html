Ajouter « {{ repo.name }} » à tico

Il faut tico 0.8.0 ou plus récent sur une Switch sous Atmosphère, connectée à Internet.

{{ index_url }}

Plus court à taper : {{ base }}/t

① Depuis la Switch

  1. Ouvrez tico et allez dans le Store.
  2. Onglet Sources (Repositories) › Ajouter un dépôt.
  3. Tapez l'adresse ci-dessus puis validez.
  4. Les paquets apparaissent dans Discover, Apps et Games.

Le dépôt sera marqué « Communauté ». Vous pouvez le passer en « Trusted » dans Sources pour installer sans confirmation.

QR code

Scannez-le avec votre téléphone pour avoir l'adresse sous les yeux.

② Depuis un PC (carte SD)

Insérez la carte SD de la Switch (ou montez-la via USB avec Hekate / DBI), puis :

curl -fsSL {{ base }}/add-to-switch.sh | bash -s -- /chemin/vers/SD

Le script sauvegarde la configuration existante de tico avant de la modifier (.bak). Exemples de chemin : /media/$USER/SWITCH (Linux), /Volumes/SWITCH (macOS), /e sous Git Bash (Windows).
